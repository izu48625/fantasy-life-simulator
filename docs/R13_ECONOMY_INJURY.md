# R1.3 転職と負傷後の選択

- 職業・階級・勤続年数・戦時手当・前線/後方配属で年収（銀貨/年）を計算。
- 転職前に基本年収・危険度・採用後階級を表示。昇進後の年収差額を年表に記録。
- 戦闘で中等度負傷、重傷、後遺症を判定。次年に治療／後方勤務／前線復帰／早期引退を選ぶ。
- FULL AUTOは本人の健康・性格で決め、SEMI/MANUALは重要選択で停止。
- 保存schema v1継続。旧保存に架空の過去収入を補完しない。
